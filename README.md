# Examen_mysql

Se genera la base de datos de un programa para la administracion de pedidos y pagos en una pizzeria, permite organizar los pedidos por fechas, categorias, porcentajes y precios

- Se utiliza MySQL para la creacion de la base de datos
- Dbeaver la interfaz

Para ejecutar las consultas se recomienda usar CTRL + INTRO
Los DROP TABLE puede presentar falla al correr todo el script, se debe hacer de manera organizada tal como le programa lo indica
